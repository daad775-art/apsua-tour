# Обмен сайта с диспетчерской программой (версия 14.0)

Сайт принимает заявки туристов и показывает им ответ диспетчера. Решения — подтвердить, отклонить, выставить счёт, назначить экскурсовода, машину и водителя — принимает программа диспетчера. Сайт ничего не придумывает: пока программа не ответила, турист видит «У диспетчера».

Пока обмен не подключён, заявки видны в админке сайта, а статус там меняют вручную.

## Секреты сервера

| Секрет | Зачем |
| --- | --- |
| `DISPATCH_API_URL` | Адрес программы, куда сайт отправляет новые и отменённые заявки (HTTPS) |
| `DISPATCH_API_TOKEN` | Токен, сайт передаёт его в заголовке `Authorization: Bearer …` |
| `DISPATCH_WEBHOOK_SECRET` | Общий секрет для подписи ответов программы сайту |

Без первых двух сайт ничего не отправляет. Без третьего `/api/dispatch-webhook` отвечает 503.

## 1. Сайт → программа: новая или отменённая заявка

`POST DISPATCH_API_URL`, тело JSON:

```json
{
  "event": "created",
  "request": {
    "siteCode": "AT-3F9C…",
    "kind": "bookings",
    "customer": { "id": "tg:987654321", "name": "Ирина", "phone": "+79401234567" },
    "date": "2026-10-25", "time": "09:00",
    "hotel": "Амра Парк-отель, Сухум, ул. Махаджиров, 1", "address": "", "note": "",
    "tour": { "id": "ritsa", "title": "Озеро Рица" },
    "format": "group", "city": "Сухум", "adults": 2, "kids": 1, "total": 7300,
    "createdAt": "2026-10-24T13:00:00.000Z"
  }
}
```

Для трансфера (`"kind": "transfers"`) вместо экскурсии приходят `direction` (`arrival` | `departure`), `terminal` (`sochi`, `adler`, `sukhum` и др.), `city`, `route`, `flight`, `format` (`individual` | `group`), `formatName` («Индивидуальный» | «Групповой» — для показа людям), `pax`, `childSeat`, `price` (рассчитана сервером, ₽; `null` — цена по запросу) и устаревшее поле `class`. С сборки 166 у трансфера два формата: индивидуальный — цена за автомобиль по маршруту, групповой — цена за пассажира × число пассажиров. `class` повторяет `format`; классы автомобилей (`comfort`, `standard`, `van`) не передаются. У заявок, созданных раньше, прежний класс переводится в формат: `comfort`/`standard`/`van` → `individual`, `group` → `group`.

Отмена туристом (возможна только до оплаты): `"event": "cancelled"`, в `request` — `siteCode`, `kind`, `dispatchNumber`, `cancelledAt`.

Ответ программы на `created` (необязателен, ждём до 8 секунд):

```json
{ "number": "D-100", "status": "pending" }
```

`number` — номер заявки в программе. С этого момента турист видит его вместо номера сайта. `status` может быть `pending`, `confirmed` или `rejected`. Если программа не ответила, заявка всё равно сохраняется, а ошибка записывается в `dispatch.error`.

## 2. Программа → сайт: решения по заявке

`POST https://<сайт>/api/dispatch-webhook`

Заголовки:
- `X-Apsua-Dispatch-Timestamp` — миллисекунды с 1970 года, не старше 5 минут;
- `X-Apsua-Dispatch-Signature` — hex HMAC-SHA256 от строки `<timestamp>.<сырое тело JSON>` с секретом `DISPATCH_WEBHOOK_SECRET`.

Тело — только поля, которые меняются:

```json
{
  "eventId": "уникальный-id-события",
  "siteCode": "AT-3F9C…",
  "kind": "bookings",
  "status": "paid",
  "number": "D-100",
  "rejectionReason": "На эту дату мест нет",
  "payment": { "id": "inv-9", "amount": 7300, "qrUrl": "https://qr.nspk.ru/…", "paymentUrl": "https://qr.nspk.ru/…", "expiresAt": "2026-10-25T18:00:00+03:00" },
  "pickupTime": "08:20",
  "pickupPoint": "Амра Парк-отель · у главного входа",
  "guide": { "name": "Астамур Кварчелия", "photo": "https://…/guide.jpg", "phone": "+79405550101", "whatsapp": "+79405550101", "languages": "Русский, английский" },
  "vehicle": { "title": "Mercedes Sprinter", "color": "белый", "registration": "А 482 ВК", "photo": "https://…/car.jpg",
               "driver": { "name": "Беслан Агрба", "photo": "https://…/driver.jpg", "phone": "+79405550202", "whatsapp": "+79405550202" } }
}
```

Правила обработки:
- `status` — одно из `pending`, `needs_info`, `confirmed`, `awaiting_payment`, `paid`, `rejected`, `cancelled`, `completed`.
- `awaiting_payment` принимается только вместе с действующим счётом: есть `id`, сумма в рублях, HTTPS-ссылка на QR СБП или оплату и срок в будущем.
- После подтверждённой оплаты счёт заменить нельзя.
- Фото и ссылки принимаются только по HTTPS. Телефоны очищаются до цифр и `+`. Неизвестные поля отбрасываются.
- Повторный `eventId` игнорируется: ответ `{"ok":true,"duplicate":true}`.
- `"guide": null` или `"vehicle": null` снимает назначение.
- После каждого изменения турист получает push-уведомление и видит новый статус на сайте без перезагрузки.

Ответы: `200 {"ok":true,"status":"…"}`, `400` — некорректные данные, `401` — подпись, `404` — заявка не найдена, `409` — повторите событие, `503` — секрет не задан.

## Что видит турист

| Статус | Карточка заявки |
| --- | --- |
| `pending` | «У диспетчера», можно отменить |
| `rejected` | Причина `rejectionReason` и кнопка «Выбрать другую дату» |
| `confirmed` | «Подтверждена», QR появится после счёта |
| `awaiting_payment` | Сумма, QR СБП, срок оплаты, кнопка «Открыть в приложении банка» |
| `paid` | Время подачи, экскурсовод и машина с госномером, кнопки «Позвонить» и WhatsApp |
| `completed` | Благодарность и просьба об отзыве |

Для трансфера водитель, машина и госномер обычно приходят за 24 часа до выезда, для экскурсии — сразу после назначения.

Проверки: `node tests/account-moderation.mjs` (блок «dispatcher exchange») и `node tests/order-notify.mjs`.
