# Manrope — 23 октября 2026

Источник: https://github.com/google/fonts/tree/main/ofl/manrope
TTF: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
Метаданные: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/METADATA.pb
Лицензия: public/fonts/Manrope-OFL.txt (SIL OFL 1.1).

Шрифт без изменения рисунка перекодирован в WOFF2 с помощью fontTools. Сохранены все глифы и вариативная ось wght 200–800. Проверены кириллица «Апсуа Тур», знак рубля и цифры. Локальная загрузка не обращается к внешнему сервису шрифтов.

Основной текст использует 400; кнопки и подписи — 500/600, заголовки — 600/700. Остальные имеющиеся веса сохранены в пределах реальной оси шрифта. Старые настройки типографики без fontVersion 130 переходят на Manrope при чтении, сохраняя размеры и остальные параметры. Записи в БД автоматически не меняются; обычное сохранение админки фиксирует настройку через существующий аудит. После миграции сохранённый явный выбор другого шрифта по-прежнему доступен. Montserrat оставлен как дополнительный вариант и для старых архивов, по умолчанию больше не используется.
